pehle concept hain
1). Access Control: Mtlb username and password se authenticate karta hain who can access the linux server/system.
                    Jiske user ko jo access h vo access kar skta hain.

dusra concept hain:
2). PAM: PAM mtlb Pluggable authentication model.
        issue bhi authentcation hota hain.

3). Network Security:
Network Security use hoti hain access allow or access restrict krne k liye..
hum external firewall par rely krne hain access allow or restrict krne k liye.
Linux server par bhi network security set kr skte hain IPTables and Firewalld k user krke.

4). SSH Hardening:
SSH: SSH mtlb Secure Shell Linux system k remote access lene k use hota hain.(unsecure  network m bhi ssh se remote access kr skte hain) company m hamesha VPN network secure hota hain.
SSH Hardening se authorized user ko hi access milega.
