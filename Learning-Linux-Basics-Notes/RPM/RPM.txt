Working with RPM:

RPM 
package/software installation k liye use hota hain
package/software uninstallation k liye use hota hain
package upgrade krne k liye
package query
update package
verify package

package install krne k liye use command:

rpm -ivh telnet.rpm

i mtlb stands for install
-V mtlb stands for Verbose, ye detail output print krta h command ka..
-h mtlb Hash progress bar, jaise jaise install hota hain # show krta hain..

Uninstall package krne k liye:

rpm -e packagename.rpm # e mtlb erase uninstall

existing package ko upgrade krne k liye

rpm -Uvh telnet.rpm
