rpm file ek software installer hota hain

Working with RPM:

RPM 
package/software installation k liye use hota hain
package/software uninstallation k liye use hota hain
package upgrade krne k liye
package query
update package
verify package

1).package install krne k liye use command:

rpm -ivh telnet.rpm

i mtlb stands for install
-V mtlb stands for Verbose, ye detail output print krta h command ka..
-h mtlb Hash progress bar, jaise jaise install hota hain # show krta hain..

2).Uninstall package krne k liye:

rpm -e packagename.rpm # e mtlb erase uninstall

3).existing package ko upgrade krne k liye

rpm -Uvh telnet.rpm

U Upper case.

4).rpm database store system m jo jo package install h uska information store krta hain..

/war/lib/rpm directory m rpm database store store hota h.

rpm databasestore --> 
kon kon se packages install h,
each package ka konsa version hain, ye information store karta hain.

5). installed package ki information k liye hum
rpm -q telnet.rpm command use krte hain.

ye command /war/lib/rpm database store ko query karta hain package information k liye

6). Package ko verify karne k liye use karte hain..
rpm -Vf <path to file>
upper case V

Verify mtlb files jo packages installed kiya tha tab, vo original package se compare karta hain n check krta hain same hain ki
data modify kiya hain..

jab hum edit, permission change krenge to vo change dikhayga.
