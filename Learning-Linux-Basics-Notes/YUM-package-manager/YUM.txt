YUM: yellow dog updater modifier

1).YUM Package Manager:

YUM mtlb Yellow Dog updater modifier
YUM free and open source package manager hain
YUM RPM based Linux system m work karta hain.
YUM RPM Se higher level package manager hain.
YUM software repositories k sath kaam karta hain.
Software repositories mtlb collection of packages..
YUM package management n Dependencies managemt dono krta hain mtlb Dependencies ko resolve krta hain..
Package ko install karne k liye dependent package ko install bhi install karta hain.

repository information /etc/yum.repo.d m store hoti hain..
repository file ka extension .repo hota hain..

YUM ek higher level package manager hain but RPM par depend karta hain package management k liye,
YUM automatic dependency resolve karta hain base package ko install krne k liye.

>YUM Package Manager:

> ye repositories remote bhi ho skt hain jisko hum HTTP/HTTPS/FTP protocol se access kr skte hain.

.d mtlb directory

> YUM phir RPM Package Manager ka use krta hain system par package ko install krne k liye

Usually RHEL OS software repositories k sath aata hain.

Redhat OS active Subscription k sath liya hain apne,

yahi apko Redhat official repo use nahi karna hain to,
