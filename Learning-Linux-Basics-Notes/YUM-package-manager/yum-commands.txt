Yum commands:

1). yum install package-name
yum install httpd 
to install any package

2). yum repolist
list karega sabhi software repository jo system m added hain.
[~]$ yum repolist

Repo id                repo name                                   status
base/7/x86_64          CentOS-7 - Base                             10,097
epel/x86_64            Extra Packages for Enterprise Linux 7 -     13,229
                       x86_64
extras/7/x86_64        CentOS-7 - Extras                           341

3). yum provide command:
Koe specific command k liye konsa package lagega/chahiye vo check krne k liye:

Example: yum provide scp
command(scp) as argument pass krte hain. 
[~]$ yum provides scp

openssh-clients-7.4p1-21.el7.x86_64 : An open source SSH client applications
Repo        : base
Matched from:
Filename    : /usr/bin/scp

SCP command is offered by open source ssh client applications.

4). yum remove httpd
to remove/uninstall any package.

5). yum update package-name

to update a single package example:
yum update telnet
to update telnet package.

already latest update hain so bolega, no packages marked for update.

5). To update all packages/ sabhi package ko update krna hain to command is:
yum update 
without any argument

ye command sabhi packages ko check karega jo update krna hain..
dependency check karega.. jo dependent package update kr k liye
