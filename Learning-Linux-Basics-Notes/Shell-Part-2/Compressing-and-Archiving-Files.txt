Viewing File Sizes: How to check size of a file in Linux ?
Ans: 
du command mtlb disk usage, jisse hum file ka size pata krte hain.

1st Way). du -sk test.jpeg ----
10000

du -sk filename --> command file ka size show karta hain hain Kilobytes main

2nd Way).du -sh filename
-h mtlb human readable form.
Example: 
du -sh test.png
98M test.png

98Mb Mb m sshow karta hain.

3rd Way). ls -lh test.jpeg
-rw-rw-r-- 1 99M Mar 13 15:48 test.img

Let us now look at widely used utility called tar.

Tar --- full form bolo ya abbriviaton 
Tape Archive.

Files created with tar are often called tarballs.
tar se hum jo files create krte hain usko kehte hain tarballs.


tar commands m bahut option hain, we will se basic use case:

tar command:

tar -C ---> 
C is used to create an archive.
archieve create krne k liye

tar -F
F is used to specify the name of the tar file to be created.
file name specify krne k liye use krte hain, jo tar file create krna hain.

n command m hum files n directores dete jo sab archive krna hain.

tar -tf test.tar 
---------------------------------
se hum test.tar file k andar ka contents dekhte hain 
tar file m kon kon si files hain.

TF option followed by tar file name is used to see the contents of the tarballs.

tar -XF
-xf flag tar file/tarballs m se content extract krne k liye use hota hain.
