Q. Using find to locate a directory ?
Ans:
Basic syntax:
find /path/to/search -type d -name "dirname"

Search for a directory named logs starting from root:
find / -type d -name "logs" 2>/dev/null

Search in your home directory:
find ~/ -type d -name "project"

Case-insensitive search:
find / -type d -iname "project"

Using locate to find a directory
locate uses a database (mlocate.db) that is updated periodically.
locate logs | grep "/logs$"

Update the locate database (if needed):
sudo updatedb
