Q1.how to change current bash shell to borne shell.
Ans:

sudo chsh -s /bin/sh

provide password

chsh -s /bin/sh bob
🔹 What it does:
chsh = change shell command in Linux.

-s = option to specify the login shell.

/bin/sh = the new shell you want to assign.

bob = the username (whose shell is being changed).

The shell change only takes effect for new login sessions.
----------------------------------------------------------------------------------

grep "^bob:" /etc/passwd
🔹 What happens here?
grep → search for matching text in a file.

^ → regex anchor meaning “start of the line”.

bob: → literal string bob:.

/etc/passwd → file that stores user account information.

Verification: Confirm the Shell Has Been Changed
Check the Password File
Run this command to verify the shell change:

grep "^bob:" /etc/passwd
Expected Output:

bob:x:1000:1000::/home/bob:/bin/sh
