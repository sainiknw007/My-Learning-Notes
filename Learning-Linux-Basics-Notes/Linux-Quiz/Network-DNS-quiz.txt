Q1). What is the IP address of the DNS Server used in this system?
Ans:
Run: cat /etc/resolv.conf and look for the line starting with nameserver.
The IP after nameserver is the DNS server used by the system.
Practical:
bob@caleston-lp10:~$ cat /etc/resolv.conf
search caleston.ca
nameserver 127.0.0.11
options ndots:5

Q2).Which file is responsible for host file-based DNS resolution?
Ans: The answer is /etc/hosts. Check this file and inspect the entries.

Q3). What is the configuration file used for the DNS Server?
Ans: The answer is /etc/resolv.conf. You can see the DNS Server configuration in this file.

Q4). Change the DNS Server to Google's DNS which is 8.8.8.8.
Ans:
Edit the file located at /etc/resolv.conf and update the nameserver IP address to 8.8.8.8
Before:
bob@caleston-lp10:~$ cat /etc/resolv.conf
search caleston.ca
nameserver 127.0.0.11
options ndots:5
Update as below:

bob@caleston-lp10:~$ cat /etc/resolv.conf
search caleston.ca
nameserver 8.8.8.8
options ndots:5
