Q1).Which of the following package managers would you use on this machine (centos-lab)?
Ans: Centos makes use of RPM and YUM.

Q2). Use an rpm command and find out the exact package name for wget installed in this server (centos-lab).
Ans: Run: rpm -qa | grep wget
[bob@centos-lab ~]$ rpm -qa | grep wget
wget-1.21.1-8.el9.x86_64

Q3). The package for the firefox browser has been downloaded under /home/bob in the centos-lab server.
Try to install it using RPM.
Ans: 
cd /home/bob
rpm -ivh firefox-128.6.0-1.el9.x86_64.rpm

Q4). command to check packge is installed or not ?
Ans:
[bob@centos-lab ~]$ rpm -q firefox
package firefox is not installed
